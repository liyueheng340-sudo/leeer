# XAU 系统宪法

> 本文件是 XAU 分析控制台（TradingAgents + local_console）的最高设计准则。
> 任何代码改动、模块新增、评审与取舍，都必须首先通过本文的检验。
> 冲突时，宪法优先于一切既有文档、注释与实现习惯。

## 第一条：以交易为目的（时刻不忘）

我们做的是一套**交易系统**，不是审计系统，也不是安全系统。

- 系统的价值 = 在交易者需要的时候，给出能用于交易的分析与建议。
- 每一条代码、每一个状态、每一道检查，都必须回答一个问题：**它对交易决策有什么帮助？**
- 任何"为了系统自身安全/整洁/好看"而存在、却不能直接服务交易的功能，都是负债，应当删除或改造。

## 第二条：军师，不是保安（分析层永不锁死）

系统对交易者只扮演一个角色：**军师**。军师的特点——

- **永远开口**：任何时候都能提供分析和建议，包括大新闻前后、震荡市、非活跃时段、数据窗口。交易者要的是"现在怎么看"，不是"现在不能看"。
- **永远诚实**：没把握就明说没把握，用风险标注表达，而不是用沉默表达。宁可给"低置信度的建议"，不可给"没有建议"。
- **决策权永远在交易者**：系统不下单、不锁仓、不替交易者做"该不该听"的决定。系统的职责是提供视角，交易者的职责是决策。

**分析层的任何"禁言"（禁模型、禁方向）都是违宪的。** 市场状态、事件窗口、传感器异常，一律以**事实标注**形式提供给模型与交易者，而不是作为"锁"。

## 第三条：唯一的保底（数据不可用才挡）

系统只有一种情况可以拒绝分析：**第一手数据不可用**——MT5 报价缺失/过期、品种身份不匹配、快照损坏。没有数据就没有分析，这是技术底线，不是策略判断。

其余一切（事件窗口、市场状态、流动性、共振、点差、EA 风控态……）都只是**上下文**，必须：

1. 如实采集、如实呈现；
2. 注入模型提示词，要求模型显式评估其影响；
3. 在报告中分级呈现（把握多大、风险在哪），但**绝不阻断分析流程**。

## 第四条：真实 > 严谨（先验证，后分析，但永不放弃分析）

- 事实层（快照、指标、事件）必须经过确定性校验，**造假/幻觉是重罪**——模型报告引用了不存在的数据，必须拒绝该报告并重跑。
- 但"校验失败"的出路是"降级呈现 + 继续分析"，不是"停止分析"。严谨是手段，交易是目的。

## 第五条：军师的纪律（保守只体现在表达上）

- 保守可以体现在：风险提示更醒目、置信度分级更细、情景分析更完整。
- 保守**不可以**体现在：拒绝开口、拒绝给方向、替交易者关闭机会。
- 例：非农窗口不是"禁言时段"，而是"加强调研时段"——提前研究预期值、做三情景分析、窗口内如实提示"当前波动剧烈，建议等待确认"。

## 第六条：违背宪法的旧设计一律改造

本宪法生效前存在的"锁"类设计（WAIT 禁模型、事件窗口禁开、降级即禁方向等），
与本宪法冲突的，一律按下述原则改造：

- `BLOCKED`（数据不可用）→ 保留（第三条）；
- `WAIT` / 禁模型（策略性锁）→ 拆除，改为"标注 + 继续分析"；
- `WATCH` / 禁方向（策略性降级）→ 改为"风险标注 + 继续给方向"；
- 报告校验（防幻觉）→ 保留，但拒绝后必须重跑而非终止。

## 检验清单（改动/评审前逐条自问）

- [ ] 这个改动是让系统更接近"军师"，还是更像"保安"？
- [ ] 交易者在大新闻/震荡/非活跃时段还能拿到分析吗？
- [ ] 任何"拒绝/阻断"的路径，是否属于"数据不可用"？
- [ ] 模型是否被要求显式评估风险，而不是被剥夺表达的机会？
- [ ] 校验失败后，系统是"降级呈现"还是"沉默"？


## 第七条：双交易模式（scalp / swing）——纪律随模式切换，验证永不丢失

系统同时服务两种交易风格，**绝不互相污染**：

- **scalp（剥头皮）**：M1 入场、贴关键价位（±1.0 ATR）、快进快出，TP/SL 上限 5/3 ATR；
- **swing（日内波段）**：M15 主图、D1/H4 过滤、持仓 1-6 小时，入场容差 ±2.5 ATR、TP/SL 上限 8/5 ATR，止盈分批（第一目标 1:1.5 并让利润奔跑），默认不隔夜。

纪律（对应 prompt_rules.MODE_RULES 与 report_validation._mode_limits 同表）：

1. **模式是任务的属性，不是全局设置**——每个任务快照记录 mode，前端一键切换；
2. **prompt 与验收必须使用同一张参数表**——模型看到的纪律与校验执行的阈值永远一致；
3. **复盘按模式分组**（review_stats by_mode）——实证哪种模式在何种情境（IV/共振/方向）下有 edge，
   不许用"我猜的"代替"测出来的"；
4. 模式切换**不得影响数据可用性判定**——BLOCKED 只由第三条决定。

## 第八条：IV 波动层（期权市场定价的波动预期）

IV（GLD 期权链推导）是**波动环境过滤器**，与价格结构、宏观同等重要：

- 只描述**波动幅度预期**，不提供方向——direction 仍以共振/结构/宏观为准；
- 高 IV（IV 显著高于 HV）：波动易收缩，偏突破/趋势策略，止损可放宽；
- 低 IV（IV 显著低于 HV）：波动扩张概率上升，偏区间/回归策略，止损收紧并警惕突然扩张；
- IV 与价格结构明显背离时：优先降低仓位或观望（风险标注呈现，不阻断）；
- IV 数据不可用时：如实验证其他事实层（第三条），**标注缺失即可，绝不因缺 IV 拒绝分析**。

IV 指标的落地纪律：
- ATM IV 用 SVI 拟合（只 OTM+ATM 合约，无套利约束），不用单档 strike 硬取；
- skew 用 25-delta 近似（put−call IV 差），正 = 下行偏斜（机构买保护，黄金常态）；
- IV Rank 依赖每日缓存累积，样本不足时如实标注"数据积累中"，不虚构百分位；
- 数据源失败静默降级（同 macro/news 纪律），缓存 TTL 内不重复抓取。
